# AWS Cloud

## Overview

Amazon Web Services (AWS) is a comprehensive cloud computing platform that provides a wide range of services for building and deploying applications.

- [ ] AWS fundamentals and core services
- [ ] EC2 (Elastic Compute Cloud)
- [ ] VPC (Virtual Private Cloud) and networking
- [ ] S3 (Simple Storage Service)
- [ ] IAM (Identity and Access Management)
- [ ] Lambda and serverless computing
- [ ] ECS/EKS for container orchestration
- [ ] CloudFormation for Infrastructure as Code
- [ ] CloudWatch for monitoring
- [ ] AWS CLI and SDKs
