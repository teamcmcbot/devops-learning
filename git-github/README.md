# Git & GitHub

## Overview

Git is a distributed version control system, and GitHub is a web-based Git repository hosting service with collaboration features.

## Learning Topics

- [ ] Git fundamentals (init, add, commit, push, pull)
- [ ] Branching and merging strategies
- [ ] Rebasing and cherry-picking
- [ ] GitHub Actions for CI/CD
- [ ] Pull requests and code reviews
- [ ] Git hooks
- [ ] Advanced Git workflows (GitFlow, GitHub Flow)
