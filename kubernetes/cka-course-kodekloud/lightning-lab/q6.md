# Question 6

Take the backup of ETCD at the location `/opt/etcd-backup.db` on the `controlplane` node.

Troubleshoot and fix the issues

## Documentation 
- Search for "etcd backup"
- https://kubernetes.io/docs/tasks/administer-cluster/configure-upgrade-etcd/#backing-up-an-etcd-cluster
- There is a "Built-in snapshot" and "Volume snapshot", I am not really sure what is the difference, the solution uses the volume snapshot.

## What I did:

  --cacert=<trusted-ca-file> --cert=<cert-file> --key=<key-file> \

## Solution

Take a help of command etcdctl snapshot save --help options.

```bash
export ETCDCTL_API=3
etcdctl snapshot save --cacert=/etc/kubernetes/pki/etcd/ca.crt --cert=/etc/kubernetes/pki/etcd/server.crt --key=/etc/kubernetes/pki/etcd/server.key --endpoints=127.0.0.1:2379 /opt/etcd-backup.db
```
