# Question 3

A kubeconfig file called `admin.kubeconfig` has been created in `/root/CKA`. There is something wrong with the configuration. Troubleshoot and fix it.


Fix /root/CKA/admin.kubeconfig

## What I did
- Compare `/etc/kubernetes/admin.conf` against `/root/CKA/admin.kubeconfig`
- saw that the admin.kubeconfig file has this configration that seems to be using wrong port number `server: https://controlplane:4380`
- for verification, i checked in `/etc/kubernetes/manifests/kube-apiserver.yaml` for the port number in this section: `- --secure-port=6443`, not sure if this is the correct way to verify the port?

## Solution
Make sure the port for the kube-apiserver is correct. So for this change port from `4380` to `6443`.
