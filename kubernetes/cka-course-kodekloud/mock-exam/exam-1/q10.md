# Mock Exam 1 - Question 10

## Task

Deploy a **Vertical Pod Autoscaler (VPA)** with name **analytics-vpa** for the deployment named **analytics-deployment** in the **default** namespace.

The VPA should automatically adjust the **CPU and memory requests** of the pods to optimize resource utilization. Ensure that the VPA operates in **Recreate** mode, allowing it to evict and recreate pods with updated resource requests as needed.

## Topics Tested

- **Vertical Pod Autoscaler (VPA)**: Creating VPAs to auto-adjust resource requests
- **VPA Update Modes**: Understanding `Off`, `Initial`, `Recreate`, and `Auto` modes
- **Resource Policies**: Configuring which resources (CPU/memory) to control
- **Container Policies**: Applying VPA rules to specific or all containers

### Official Documentation

- [Vertical Pod Autoscaler](https://github.com/kubernetes/autoscaler/tree/master/vertical-pod-autoscaler)
- [VPA API Reference](https://github.com/kubernetes/autoscaler/blob/master/vertical-pod-autoscaler/pkg/apis/autoscaling.k8s.io/v1/types.go)

## Sample Solution

```yaml
apiVersion: autoscaling.k8s.io/v1
kind: VerticalPodAutoscaler
metadata:
  name: analytics-vpa
  namespace: default
spec:
  targetRef:
    apiVersion: apps/v1
    kind: Deployment
    name: analytics-deployment
  updatePolicy:
    updateMode: "Recreate"
  resourcePolicy:
    containerPolicies:
      - containerName: "*"
        controlledResources:
          - cpu
          - memory
```

### Apply the configuration

```bash
# Create the VPA
kubectl apply -f analytics-vpa.yaml
```

## Verification

```bash
# Check VPA
kubectl get vpa analytics-vpa

# Describe for details and recommendations
kubectl describe vpa analytics-vpa
```

## Key Points

| Parameter            | Value                  |
| -------------------- | ---------------------- |
| VPA Name             | `analytics-vpa`        |
| Target Deployment    | `analytics-deployment` |
| Update Mode          | `Recreate`             |
| Controlled Resources | `cpu`, `memory`        |

## VPA Update Modes

| Mode       | Description                                          |
| ---------- | ---------------------------------------------------- |
| `Off`      | VPA only provides recommendations, no action         |
| `Initial`  | Only applies recommendations at pod creation         |
| `Recreate` | Evicts and recreates pods with new resource requests |
| `Auto`     | Currently same as Recreate                           |

## Key Concepts

- **VPA** = Vertical Pod Autoscaler (adjusts CPU/memory requests)
- **Recreate mode** = Pods are evicted and recreated with updated resources
- Unlike HPA, VPA adjusts resources per pod, not pod count
