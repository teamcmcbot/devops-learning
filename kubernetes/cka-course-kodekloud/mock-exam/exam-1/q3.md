# Mock Exam 1 - Question 3

## Task

On **controlplane** node, identify all **CRDs** related to **VerticalPodAutoscaler** and save their names into the file `/root/vpa-crds.txt`.

## Topics Tested

- **Custom Resource Definitions (CRDs)**: Listing and filtering CRDs in a cluster
- **kubectl Output Filtering**: Using `grep`, `awk`, and other Linux commands to filter output
- **File Redirection**: Saving command output to files using `>`
- **Vertical Pod Autoscaler**: Understanding VPA components and CRDs

### Official Documentation

- [Custom Resources](https://kubernetes.io/docs/concepts/extend-kubernetes/api-extension/custom-resources/)
- [Vertical Pod Autoscaler](https://github.com/kubernetes/autoscaler/tree/master/vertical-pod-autoscaler)

## Sample Solution

```bash
# List all CRDs and filter for VPA-related ones, save to file
kubectl get crd | grep verticalpodautoscaler | awk '{print $1}' > /root/vpa-crds.txt

# Alternative: More precise filtering
kubectl get crd -o name | grep verticalpodautoscaler | cut -d'/' -f2 > /root/vpa-crds.txt
```

## Verification

```bash
# View the contents of the file
cat /root/vpa-crds.txt
```

## Expected Output (example)

```
verticalpodautoscalercheckpoints.autoscaling.k8s.io
verticalpodautoscalers.autoscaling.k8s.io
```

## Key Concepts

- **CRD** = Custom Resource Definition
- **VPA** = Vertical Pod Autoscaler (adjusts CPU/memory requests)
- Use `kubectl get crd` to list all Custom Resource Definitions
