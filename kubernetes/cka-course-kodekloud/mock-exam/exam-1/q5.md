# Mock Exam 1 - Question 5

## Task

Create a deployment named **hr-web-app** using the image `kodekloud/webapp-color` with **2 replicas**.

## Topics Tested

- **Deployments**: Creating deployments with specific replica counts
- **Imperative Commands**: Using `kubectl create deployment` with flags
- **Scaling**: Setting initial replica count during deployment creation

### Official Documentation

- [Deployments](https://kubernetes.io/docs/concepts/workloads/controllers/deployment/)
- [kubectl create deployment](https://kubernetes.io/docs/reference/kubectl/generated/kubectl_create/kubectl_create_deployment/)

## Sample Solution

```bash
# Create deployment with 2 replicas
kubectl create deployment hr-web-app --image=kodekloud/webapp-color --replicas=2
```

## Verification

```bash
# Check deployment
kubectl get deployment hr-web-app

# Check pods are running
kubectl get pods -l app=hr-web-app

# Describe deployment for details
kubectl describe deployment hr-web-app
```

## Expected Output

```
NAME         READY   UP-TO-DATE   AVAILABLE   AGE
hr-web-app   2/2     2            2           10s
```

## Key Points

| Parameter       | Value                    |
| --------------- | ------------------------ |
| Deployment Name | `hr-web-app`             |
| Image           | `kodekloud/webapp-color` |
| Replicas        | `2`                      |
