# Mock Exam 1 - Question 6

## Task

A new application **orange** is deployed. There is something wrong with it. **Identify and fix the issue**.

## Topics Tested

- **Troubleshooting Pods**: Identifying why pods are failing
- **kubectl describe**: Reading events and error messages
- **kubectl logs**: Viewing container and init container logs
- **Pod Editing**: Exporting, modifying, and recreating pods
- **Init Containers**: Understanding init container failures and how to fix them

### Official Documentation

- [Debug Pods](https://kubernetes.io/docs/tasks/debug/debug-application/debug-pods/)
- [Debug Running Pods](https://kubernetes.io/docs/tasks/debug/debug-application/debug-running-pod/)
- [Init Containers](https://kubernetes.io/docs/concepts/workloads/pods/init-containers/)

## Sample Solution

### Step 1: Identify the Issue

```bash
# Check pod status
kubectl get pod orange

# Describe pod to see events and errors
kubectl describe pod orange

# Check logs
kubectl logs orange

# Check init container logs (if any)
kubectl logs orange -c <init-container-name>
```

### Step 2: Common Issues to Look For

| Issue                  | How to Identify                             |
| ---------------------- | ------------------------------------------- |
| Image pull error       | `ImagePullBackOff` or `ErrImagePull` status |
| Init container failure | `Init:Error` or `Init:CrashLoopBackOff`     |
| Command/args typo      | Check `describe` output for command         |
| Resource issues        | Check events for scheduling failures        |

### Step 3: Fix the Issue

```bash
# Edit the pod to fix the issue (if editable)
kubectl edit pod orange

# Or delete and recreate with corrected YAML
kubectl get pod orange -o yaml > orange.yaml
# Edit orange.yaml to fix the issue
kubectl delete pod orange
kubectl apply -f orange.yaml
```

### Common Fix: Init Container Command Typo

If the init container has a typo (e.g., `sleeeep` instead of `sleep`):

```bash
# Export pod definition
kubectl get pod orange -o yaml > /tmp/orange.yaml

# Edit and fix the typo
vi /tmp/orange.yaml
# Change: sleeeep → sleep

# Delete and recreate
kubectl delete pod orange
kubectl apply -f /tmp/orange.yaml
```

## Verification

```bash
# Check pod is running
kubectl get pod orange

# Expected: STATUS = Running
```
