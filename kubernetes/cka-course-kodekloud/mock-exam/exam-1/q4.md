# Mock Exam 1 - Question 4

## Task

Create a service named **messaging-service** to expose the **messaging** pod within the cluster on port **6379**. The messaging pod is running in the **default** namespace.

Use **imperative commands**.

## Topics Tested

- **Services - ClusterIP**: Exposing pods internally within the cluster
- **Imperative Commands**: Using `kubectl expose` to create services quickly
- **Service Discovery**: Understanding how pods communicate via services

### Official Documentation

- [Service](https://kubernetes.io/docs/concepts/services-networking/service/)
- [kubectl expose](https://kubernetes.io/docs/reference/kubectl/generated/kubectl_expose/)

## Sample Solution

```bash
# Expose the messaging pod as a ClusterIP service
kubectl expose pod messaging --name=messaging-service --port=6379
```

## Verification

```bash
# Check the service was created
kubectl get svc messaging-service

# Describe the service to verify configuration
kubectl describe svc messaging-service

# Check endpoints (should show the pod IP)
kubectl get endpoints messaging-service
```

## Expected Output

```
NAME                TYPE        CLUSTER-IP      EXTERNAL-IP   PORT(S)    AGE
messaging-service   ClusterIP   10.96.xxx.xxx   <none>        6379/TCP   5s
```

## Key Points

| Parameter    | Value                                |
| ------------ | ------------------------------------ |
| Service Name | `messaging-service`                  |
| Target       | `messaging` pod                      |
| Port         | `6379`                               |
| Type         | `ClusterIP` (default, internal only) |
| Namespace    | `default`                            |
