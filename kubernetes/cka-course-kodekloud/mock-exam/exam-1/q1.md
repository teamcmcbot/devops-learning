# Mock Exam 1 - Question 1

Create a Pod mc-pod in the mc-namespace namespace with three containers. The first container should be named mc-pod-1, run the nginx:1-alpine image, and set an environment variable NODE_NAME to the node name. The second container should be named mc-pod-2, run the busybox:1 image, and continuously log the output of the date command to the file /var/log/shared/date.log every second. The third container should have the name mc-pod-3, run the image busybox:1, and print the contents of the date.log file generated by the second container to stdout. Use a shared, non-persistent volume.

## Topics Tested

- **Multi-container Pods**: Creating a pod with multiple containers
- **Environment Variables from Downward API**: Setting env vars using `fieldRef` to get node/pod metadata (`spec.nodeName`)
- **Container Commands & Args**: Running custom shell commands in containers
- **Volumes - emptyDir**: Creating non-persistent shared volumes between containers
- **Volume Mounts**: Mounting volumes to specific paths in containers

## Sample Solution

```yaml
apiVersion: v1
kind: Namespace
metadata:
  name: mc-namespace
---
apiVersion: v1
kind: Pod
metadata:
  name: mc-pod
  namespace: mc-namespace
spec:
  containers:
    # Container 1: nginx with NODE_NAME env var
    - name: mc-pod-1
      image: nginx:1-alpine
      env:
        - name: NODE_NAME
          valueFrom:
            fieldRef:
              fieldPath: spec.nodeName

    # Container 2: writes date to shared log every second
    - name: mc-pod-2
      image: busybox:1
      command: ["/bin/sh", "-c"]
      args:
        - while true; do date >> /var/log/shared/date.log; sleep 1; done
      volumeMounts:
        - name: shared-volume
          mountPath: /var/log/shared

    # Container 3: reads and prints the date.log file
    - name: mc-pod-3
      image: busybox:1
      command: ["/bin/sh", "-c"]
      args:
        - tail -f /var/log/shared/date.log
      volumeMounts:
        - name: shared-volume
          mountPath: /var/log/shared

  # Shared emptyDir volume (non-persistent)
  volumes:
    - name: shared-volume
      emptyDir: {}
```
