# Mock Exam 1 - Question 8

## Task

Create a **Persistent Volume** with the given specification:

- **Volume name**: `pv-analytics`
- **Storage**: `100Mi`
- **Access mode**: `ReadWriteMany`
- **Host path**: `/pv/data-analytics`

## Topics Tested

- **Persistent Volumes (PV)**: Creating PVs with specific capacity and access modes
- **Access Modes**: Understanding `ReadWriteOnce`, `ReadOnlyMany`, `ReadWriteMany`
- **hostPath Volumes**: Using local node storage for PVs (dev/test only)
- **Storage Configuration**: Defining storage capacity and reclaim policies

### Official Documentation

- [Persistent Volumes](https://kubernetes.io/docs/concepts/storage/persistent-volumes/)
- [Access Modes](https://kubernetes.io/docs/concepts/storage/persistent-volumes/#access-modes)

## Sample Solution

```yaml
apiVersion: v1
kind: PersistentVolume
metadata:
  name: pv-analytics
spec:
  capacity:
    storage: 100Mi
  accessModes:
    - ReadWriteMany
  hostPath:
    path: /pv/data-analytics
```

### Apply the configuration

```bash
# Create the PV
kubectl apply -f pv-analytics.yaml

# Or use heredoc
cat <<EOF | kubectl apply -f -
apiVersion: v1
kind: PersistentVolume
metadata:
  name: pv-analytics
spec:
  capacity:
    storage: 100Mi
  accessModes:
    - ReadWriteMany
  hostPath:
    path: /pv/data-analytics
EOF
```

## Verification

```bash
# Check PV was created
kubectl get pv pv-analytics

# Describe for details
kubectl describe pv pv-analytics
```

| Parameter      | Value                 |
| -------------- | --------------------- |
