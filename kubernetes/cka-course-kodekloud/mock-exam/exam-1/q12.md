# Mock Exam 1 - Question 12

## Task

One co-worker deployed an nginx helm chart **kk-mock1** in the **kk-ns** namespace on the cluster. A new update is pushed to the helm chart, and the team wants you to **update the helm repository** to fetch the new changes.

After updating the helm chart, **upgrade** the helm chart version to **18.1.15**.

## Topics Tested

- **Helm Repository Management**: Updating helm repos to fetch latest charts
- **Helm Upgrade**: Upgrading releases to specific chart versions
- **Helm Release Management**: Listing, inspecting, and managing helm releases
- **Helm in Namespaces**: Working with helm releases in specific namespaces

### Official Documentation

- [Helm Documentation](https://helm.sh/docs/)
- [helm repo update](https://helm.sh/docs/helm/helm_repo_update/)
- [helm upgrade](https://helm.sh/docs/helm/helm_upgrade/)

## Sample Solution

### Step 1: List current helm releases

```bash
# Check current release
helm list -n kk-ns
```

### Step 2: Update helm repositories

```bash
# Update all helm repositories to fetch latest charts
helm repo update
```

### Step 3: Upgrade the helm release

```bash
# Upgrade to specific version
helm upgrade kk-mock1 bitnami/nginx --version 18.1.15 -n kk-ns
```

> **Note**: Replace `bitnami/nginx` with the actual chart name if different. Check with `helm list -n kk-ns` to see the chart name.

### Alternative: If you need to find the repo/chart name

```bash
# List release details
helm list -n kk-ns

# Get release info
helm get all kk-mock1 -n kk-ns

# Search for nginx chart
helm search repo nginx
```

## Verification

```bash
# Verify the upgrade
helm list -n kk-ns

# Check release history
helm history kk-mock1 -n kk-ns

# Verify version
helm get metadata kk-mock1 -n kk-ns
```

## Key Points

| Command                                          | Purpose                                |
| ------------------------------------------------ | -------------------------------------- |
| `helm repo update`                               | Fetch latest chart versions from repos |
| `helm upgrade <release> <chart> --version <ver>` | Upgrade to specific version            |
| `helm list -n <ns>`                              | List releases in namespace             |
| `helm history <release>`                         | View release history                   |

## Key Helm Commands Reference

```bash
# List repos
helm repo list

# Update repos
helm repo update

# Search charts
helm search repo <name>

# List releases
helm list -n <namespace>

# Upgrade release
helm upgrade <release> <chart> --version <version> -n <namespace>

# Rollback if needed
helm rollback <release> <revision> -n <namespace>
```
