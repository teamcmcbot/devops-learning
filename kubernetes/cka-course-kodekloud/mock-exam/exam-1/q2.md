# Mock Exam 1 - Question 2

## Task

This question needs to be solved on node **node01**. To access the node using SSH, use the credentials below:

- **username**: `bob`
- **password**: `caleston123`

As an administrator, you need to prepare **node01** to install Kubernetes. One of the steps is installing a container runtime. Install the `cri-docker_0.3.16.3-0.debian.deb` package located in `/root` and ensure that the **cri-docker** service is **running** and **enabled** to start on boot.

## Topics Tested

- **SSH Access**: Connecting to remote nodes using SSH
- **Linux Package Management**: Installing `.deb` packages using `dpkg`
- **Systemd Service Management**: Enabling and starting services with `systemctl`
- **Container Runtime Installation**: Understanding Kubernetes container runtime requirements

### Official Documentation

- [Container Runtimes](https://kubernetes.io/docs/setup/production-environment/container-runtimes/)
- [Installing kubeadm](https://kubernetes.io/docs/setup/production-environment/tools/kubeadm/install-kubeadm/)

## Sample Solution

```bash
# SSH into node01
ssh bob@node01
# Password: caleston123

# Install the cri-docker package
sudo dpkg -i /root/cri-docker_0.3.16.3-0.debian.deb

# Enable cri-docker service to start on boot
sudo systemctl enable cri-docker

# Start the cri-docker service
sudo systemctl start cri-docker

# Verify the service is running
sudo systemctl status cri-docker
```

## Verification

```bash
# Check if service is enabled
systemctl is-enabled cri-docker
# Expected: enabled

# Check if service is active/running
systemctl is-active cri-docker
# Expected: active
```
