# Mock Exam 3 - Question 9

A kubeconfig file called `super.kubeconfig` has been created under `/root/CKA`. There is something wrong with the configuration. Troubleshoot and fix it.

## Topics Tested

- **Kubeconfig Files**: Understanding the structure and purpose of kubeconfig files
- **Cluster Configuration**: Configuring clusters section with correct API server endpoints
- **API Server Connection**: Understanding kube-apiserver host and port configuration
- **Kubeconfig Troubleshooting**: Diagnosing connection issues in kubeconfig
- **kubectl cluster-info**: Verifying cluster connectivity
- **Port Configuration**: Knowing the default kube-apiserver port (6443)
- **Context Configuration**: Understanding users, clusters, and contexts in kubeconfig

## Sample Solution

Verify host and port for kube-apiserver are correct.

Open the `super.kubeconfig` in vi editor.

Change the `9999` port to `6443` and run the below command to verify:

```bash
kubectl cluster-info --kubeconfig=/root/CKA/super.kubeconfig
```
