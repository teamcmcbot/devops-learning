# CKA Mock Exam 1 - Question 1

## SECTION: WORKLOADS & SCHEDULING

Solve this question on: `ssh cluster1-controlplane`

In the namespace `default`, there is a deployment called `frontend-deployment`. Create a Horizontal Pod Autoscaler (HPA), also called `frontend-deployment`, that keeps average the CPU utilization of the deployment's pods to `70%`, limiting the number of pods from a minimum of `2`, and a maximum of `10`.

## Sample Solution

SSH into the `cluster1-controlplane` host

```bash
ssh cluster1-controlplane
```

Create the Horizontal Pod Autoscaler (HPA)

Option 1: Using an Imperative Command

```bash
kubectl autoscale deployment frontend-deployment --cpu-percent=70 --min=2 --max=10
```

Option 2: Using a YAML Manifest

```yaml
apiVersion: autoscaling/v2
kind: HorizontalPodAutoscaler
metadata:
  name: frontend-deployment
  namespace: default
spec:
  scaleTargetRef:
    apiVersion: apps/v1
    kind: Deployment
    name: frontend-deployment
  minReplicas: 2
  maxReplicas: 10
  metrics:
  - type: Resource
    resource:
      name: cpu
      target:
        type: Utilization
        averageUtilization: 70
```
