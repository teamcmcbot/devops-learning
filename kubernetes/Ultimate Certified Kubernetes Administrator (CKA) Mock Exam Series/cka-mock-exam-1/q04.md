# CKA Mock Exam 1 - Question 4

## SECTION: STORAGE

Solve this question on: `ssh cluster1-controlplane`


A persistent volume called `papaya-pv-cka09-str` is already created with a storage capacity of `150Mi`. It's using the `papaya-stc-cka09-str` storage class with the path `/opt/papaya-stc-cka09-str`.


A persistent volume claim named `papaya-pvc-cka09-str` has also been created on this cluster. This PVC has requested `50Mi` of storage from `papaya-pv-cka09-str` volume.


Resize the PVC to `80Mi` and make sure the PVC is in the `Bound` state.

## Sample Solution

SSH into the `cluster1-controlplane` host

```bash
ssh cluster1-controlplane
```

Edit `papaya-pv-cka09-str` PV:

```bash
kubectl get pv papaya-pv-cka09-str -o yaml > /tmp/papaya-pv-cka09-str.yaml
```

Edit the template:

```bash
vi /tmp/papaya-pv-cka09-str.yaml
```

Delete all entries for uid:, annotations, status:, claimRef: from the template.
Edit `papaya-pvc-cka09-str` PVC:

```bash
kubectl get pvc papaya-pvc-cka09-str -o yaml > /tmp/papaya-pvc-cka09-str.yaml
```

Edit the template:

```bash
vi /tmp/papaya-pvc-cka09-str.yaml
```

Under `resources:` -> `requests:` change `storage: 50Mi` to `storage: 80Mi` and save the template.
Delete the exsiting PVC:

```bash
kubectl delete pvc papaya-pvc-cka09-str
```

Delete the exsiting PV and create using the template:

```bash
kubectl delete pv papaya-pv-cka09-str
kubectl apply -f /tmp/papaya-pv-cka09-str.yaml
```

Create the PVC using template:

```bash
kubectl apply -f /tmp/papaya-pvc-cka09-str.yaml
```

To achieve the same solution using a patch, follow these steps:

Edit `papaya-pv-cka09-str` PV:

```bash
kubectl patch pv papaya-pv-cka09-str --type=json -p='[{"op": "remove", "path": "/metadata/uid"},{"op": "remove", "path": "/metadata/annotations"},{"op": "remove", "path": "/status"},{"op": "remove", "path": "/spec/claimRef"}]'
```

Edit `papaya-pvc-cka09-str` PVC to update the storage request:

```bash
kubectl patch pvc papaya-pvc-cka09-str --type=json -p='[{"op": "replace", "path": "/spec/resources/requests/storage", "value": "80Mi"}]'
```

No need to delete the existing PVC and PV; the patch commands will directly update them.
